The project's documentation, published at `docs.<zone>`. Replace this
page with your own.

- [Getting started](getting-started.md)

Each page here is Markdown, built to HTML by `make docs` into
`build/docs/`, and released by a sync of that folder to the project's
`docs` bucket, as the UI is to `www`. A link to another page names its
`.md` file; the build makes it `.html`.
